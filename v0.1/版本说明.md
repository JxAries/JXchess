# JXchess v0.1.0 版本说明

> 本文档用于填写 GitHub Release 的描述，只在发布前为当次版本撰写；各版本的说明相互独立。

## 简介

面向中文棋手的开源免费国际象棋工具。v0.1.0 是首个可运行版本，提供复盘与摆棋两块单机功能，以 Windows 桌面程序发布。

## 下载

- `JXchess_0.1.0_x64-setup.exe`：安装版，可选择安装目录、自动创建快捷方式，并可从系统"应用"中卸载。
- `JXchess.exe`：免安装版，双击直接运行。

Windows 10 / 11，无需安装任何运行环境。安装包未做代码签名，首次运行若出现"未知发布者"提示，选择继续运行即可。

## 本版功能

- 复盘：PGN 导入与导出，逐步回放与任意跳转，点击或拖拽走子，合法走法校验与升变选择，被将军时的暗红圆形提醒，木质敲击音效，棋盘翻转。
- 多分支复盘：在任意位置走出与主线不同的着法即生成支线；"新建分支"可先待命再落子，"删除分支"删除当前支线；棋谱面板主线按回合显示，支线按 `1.d4 Nf6`、`1.… c5 2.Nf3` 形式显示，并随当前着法自动横向滚动，当前支线与当前着法都有高亮。
- 终局结果：主线最后一步下方显示标准结果，如 `1-0 · 白棋获胜`、`0-1 · 黑棋获胜`、`½-½ · 平局`。
- 棋谱面板：显示双方得子，重叠紧凑排布不跑版；所有反馈都在面板内一行小字上完成，没有浮动提示框。
- 摆棋：自由摆放研究局面，支持选择移动、擦除、放置与拖拽；可设置先手方与双方易位权利，导出准确 FEN，或带着当前局面直接去复盘续走。
- 界面：报纸风视觉，浅色棋盘以细线分格，暖灰纸色背景，单一低饱和深红强调色，按钮统一细边框幽灵样式。
- 首页：居中 logo、随机生成并缓慢旋转的棋子飘落背景；鼠标为带锁定标记的黑王指针，黑马保持较大间距在后方跟随，静止时在附近小范围蹦跳。
- 窗口图标：白底圆角矩形内放大的项目 logo。

## 已知说明

- 导出 PGN 保留主线；变例受 PGN 文本结构所限暂不随导出保留。
- 未导入 PGN（新建对局或从摆棋续走）时默认不启用变例，走新着法会覆盖其后走法，需要分支时先点"新建分支"。
- 仅提供 Windows x64 版本。
- 棋子样式 gioco：作者 sadsnake1，许可 CC BY-NC-SA 4.0，来自 lichess/lila 项目。
