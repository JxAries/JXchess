# JXchess v0.1.0 版本说明

> 本文档用于填写 GitHub Release 的描述，只在发布前为当次版本撰写；每个版本的说明各自独立。

## 简介

面向中文棋手的开源免费国际象棋工具。v0.1.0 是首个可运行版本，提供复盘与摆棋两块单机功能。

## 本版功能

- 复盘：PGN 导入与导出，逐步回放与任意跳转，点击或拖拽走子，合法走法校验与升变选择，被将军时的红格提醒，木质敲击音效，棋盘翻转。
- 多分支复盘：在任意位置走出与主线不同的着法即生成变着支线，可用“新建分支”“删除分支”管理；棋谱面板主线按回合显示，支线以小字列出并自动横向滚动跟随当前着法，当前主线步与当前支线都带底色高亮。
- 终局结果：主线最后一步下方显示标准结果，如 `1-0 · 白棋获胜`、`0-1 · 黑棋获胜`、`½-½ · 平局`。
- 棋谱面板：显示双方得子，紧凑排布不跑版；超长棋谱在面板内滚动。
- 摆棋：自由摆放研究局面，支持选择移动、擦除、放置与拖拽；可设置先手方与双方易位权利，导出准确 FEN，或带着当前局面直接去复盘续走。
- 首页：居中 logo、棋子以不同倾角缓缓飘落的背景动效，鼠标为黑王指针、黑马在后跟随并做跳跃动作。

## 运行方式

```bash
cd v0.1
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 构建产物在 v0.1/dist
```

页面不能直接双击 HTML 打开，必须通过本地服务或部署后的网址访问。

## 已知说明

- 导出 PGN 保留主线；变例受 PGN 文本结构所限暂不随导出保留。
- 未导入 PGN（新建对局或从摆棋续走）时默认不启用变例，走新着法会覆盖其后走法，需要分支时先用“新建分支”。
- 棋子样式 gioco：作者 sadsnake1，许可 CC BY-NC-SA 4.0，来自 lichess/lila 项目。
