# JXchess v0.1.0 版本说明

> 本文档用于填写 GitHub Release 描述；每个小版本更新前同步修改本文件。

## 简介

面向中文棋手的开源免费国际象棋工具。首个可运行版本为“复盘 + 摆棋”单机工具。

## 本版功能

- 复盘：PGN 导入与导出、逐步回放与任意跳转、点击与拖拽走子、升变选择、合法走法校验、被将军红格提醒、木质走子音效、棋盘翻转。
- 多分支复盘：导入棋谱后在任一位置走出不同着法会生成“变着”小字行，点击可进入该支线回放。
- 棋谱面板：主线按回合显示，变着以浅色单行记录，超宽时可横向滚动；终局在最后一步下方显示标准结果（1-0 / 0-1 / ½-½）。
- 摆棋：自由摆放研究局面；选择移动、擦除、放置三种模式与拖拽；可选先手方与双方易位权利，导出准确 FEN，或带着局面直接去复盘。
- 首页：居中大 logo 与轻量棋子飘落动效，预留更多入口。

## 运行方式

```bash
cd v0.1
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 构建产物在 v0.1/dist
```

页面不能直接双击 HTML 打开，必须通过本地服务或部署后的网址访问。

## 已知说明

- 导出 PGN 保留主线；变例因 PGN 文本结构暂不随导出保留。
- 无 PGN 导入（新建对局/摆棋续走）时不启用变例，走新着法会覆盖其后走法。
