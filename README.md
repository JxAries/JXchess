# JXchess

面向中文棋手的开源免费国际象棋工具。0.x 阶段做单机学棋工具，从复盘与摆棋做起；引擎分析、揭棋与盲棋、账号在后续版本，联网功能安排在 1.x。

当前版本：**v0.1.0**

## 下载

在 GitHub 的 [Releases](https://github.com/JxAries/JXchess/releases) 页面下载 Windows 桌面版：

- `JXchess_0.1.0_x64-setup.exe`：安装版，可选择安装目录、自动创建快捷方式，并可从系统"应用"里卸载。
- `JXchess.exe`：免安装版，双击即可运行，适合放进 U 盘或任意目录携带。

Windows 10 / 11，无需预先安装任何运行环境。安装包内置了 WebView2 运行时的引导程序，若系统缺少会自动补装（这一步需要联网）；免安装版依赖系统已有的 WebView2 运行时。安装包未做代码签名，首次运行若出现系统的"未知发布者"提示，选择继续运行即可。

> 仓库源码里不含可执行文件，打包产物输出在 `v0.1/src-tauri/target/` 与 `v0.1/release/`，两者都已加入 `.gitignore`。

## 功能

- **复盘**：PGN 导入与导出、逐步回放与任意跳转、点击或拖拽走子、合法走法校验与升变选择、被将军时的红光提醒、木质敲击音效、棋盘翻转。选中棋子后单击目标格即可落子，一次点击生效；拖拽时实时显示该子的合法落点。
- **多分支复盘**：在任意位置走出与主线不同的着法即生成支线；"新建分支"可先待命再落子，"删除分支"删除当前支线。棋谱面板主线按回合显示，支线按 `1.d4 Nf6`、`1.… c5 2.Nf3` 格式显示，并随当前着法自动横向滚动；当前支线与当前着法都有高亮。
- **终局结果**：主线最后一步下方显示 `1-0 · 白棋获胜`、`0-1 · 黑棋获胜` 或 `½-½ · 平局`。
- **棋谱面板**：显示双方得子，重叠紧凑排布不跑版；所有反馈都在面板内的一行小字上完成，没有浮动提示框；播放控制就在面板中。
- **摆棋**：自由摆放研究局面，支持选择移动、擦除、放置与拖拽；同一枚棋子放到已有它的格子即可移除；可设置先手方与双方易位权利，导出准确 FEN，或带着当前局面直接去复盘续走。
- **界面**：报纸风视觉。棋盘采用两级浅灰配色（浅格 `#dcdcdc`、深格 `#c9c9c9`、格线 `#939393`），深色格内有向内辐射的细排线；暖灰纸色背景，单一低饱和深红强调色，按钮统一为细边框幽灵样式。
- **首页**：居中 logo、随机生成并缓慢旋转的棋子飘落背景；鼠标为黑王指针，黑马与王同尺寸、保持固定间距在后方延迟跟随。

## 为什么做 JXchess

我叫谏贤，一名国际象棋爱好者，也是计算机专业的学生。做这个软件的最初动机很朴素：我自己复盘对局时，常常知道哪步走得不好，却说不出为什么；身边学棋的孩子和他们的家长，也卡在同一个地方。市面上的工具帮不了他们，那我就自己做一个。

想解决的问题主要有三个：

**复盘看得懂该走哪步，看不懂为什么。** lichess、chess.com、国象联盟等能帮棋手记录对局、给出引擎评估、标出好棋坏棋，但几乎都不会解释为什么这步是好棋。对水平不高的棋手来说，看到最佳着法往往等于没看到，不理解背后的意图，下次遇到同样的局面还是走不出来。真人教练能讲透，但贵、要预约、不随叫随到。我想做一个会把每一步棋讲明白的复盘工具。

**想下点别的地方没有的玩法。** 变体玩法方面，chess.com 算最丰富，lichess 也有 8 种变体，但它们都是正统棋的变体。在中国象棋圈流行的揭棋，把棋子背面朝上随机摆放，走出第一步才翻开，这种玩法在国际象棋世界几乎是空白。连国际象棋程序员社区都为国际象棋揭棋设计好了记谱规范，却始终没有平台真正把它做出来。我想把揭棋带进国际象棋，再配上两种为进阶玩家准备的盲棋玩法。

**国内棋手的信息是断的。** 想找最近家门口有什么比赛、什么时候报名、比赛结果如何、哪个教练靠谱，国内棋手基本靠口口相传；lichess 上的新闻是英文的，帮不上忙。我想做一块中文资讯区，把赛事、棋协公告、比赛结果、培训信息一块一块摆好并注明来源。

JXchess 是一个开源、免费、个人维护的项目。商业与盈利目前完全不考虑。

## 功能设想与路线图

0.x 阶段以单机为主，一个人离线也能把核心功能用顺，这个阶段不需要服务器；1.x 阶段进入联网。每个小版本都必须可运行、可独立发布，并以 GitHub Release 的形式正式发布。

| 版本 | 内容 |
|---|---|
| **v0.1.0** | 复盘棋盘：工程搭建、棋盘复盘（棋谱导入、逐步回放、任意跳转）、合法走法判定、摆棋研究、棋谱导出。第一个可运行版本。 |
| v0.2.0 | 引擎分析：接入本地 Stockfish，提供评估条、推荐着法、整局好坏总览。 |
| v0.3.0 | 揭棋与盲棋：揭棋规则层与吃子记录区，两种盲棋玩法。0.x 阶段的主打亮点。 |
| v0.4.0 | 账号：本地账号，对局与复盘存档管理。 |
| v1.0.0 | 首个正式大版本：功能收口、稳定性完善、打包为桌面软件、正式发布。 |
| 1.x | 联网阶段：联机对弈与中文资讯聚合为主；会讲棋的复盘视经费情况安排。 |

引擎采用开源免费的 Stockfish 本地运行，作为基本功跟上，但不当作卖点——对弈和题库不是我们的主场，我们只补三块拼图：会讲棋的复盘、翻棋类的变体玩法、中文资讯整合。习题模式与开局训练留在案头，等 1.x 之后按实际反馈再排期。

揭棋规则草案（上线前还会细化，最终规则以对应版本的更新说明为准）：

1. 开局时，除王以外的 15 个棋子全部正面朝下、随机打乱，摆在开局的起始格上。
2. 暗子的第一步按它所在格原本该有的棋子的走法走。走出这一步后翻开并显示身份，此后按真实身份正常行棋。
3. 王是明子，始终按常规规则行棋。
4. 王可以与仍在车位的暗子易位，长短易位都须满足普通易位的条件；不能与已经翻开的明车易位。
5. 过路兵规则在揭棋中不采用。
6. 翻出来的兵走到对方底线可正常升变。
7. 被吃掉的暗子记录为暗子，不公开真实身份，棋盘外保留一块区域记录双方吃到哪些子。
8. 揭棋早期版本不做棋谱记录，也不接入引擎，先把完整下完一盘棋做好。

两种盲棋玩法：**全同贴图盲棋**（两方棋子使用同一贴图，其余规则与普通对局一致）与**无棋盘盲棋**（整盘不渲染棋盘和棋子，只保留记谱，走棋通过输入标准着法完成）。
