# JXchess

面向中文棋手的开源免费国际象棋工具。0.x 阶段做单机学棋工具，先从复盘与摆棋做起；引擎分析、揭棋与盲棋、账号在后续版本，联网功能安排在 1.x。

当前版本：**v0.1.0**

## 下载

在 GitHub 的 Releases 页面下载 Windows 桌面版，解压或安装后直接使用，不需要任何额外环境：

- `JXchess_0.1.0_x64-setup.exe`：安装版，可选择安装目录、自动创建快捷方式，并可从系统"应用"里卸载。
- `JXchess.exe`：免安装版，双击即可运行，适合放进 U 盘或任意目录携带。

安装包未做代码签名，首次运行若出现系统的"未知发布者"提示，选择继续运行即可。

## 功能

- **复盘**：PGN 导入与导出、逐步回放与任意跳转、点击或拖拽走子、合法走法校验与升变选择、被将军时的暗红圆形提醒、木质敲击音效、棋盘翻转。
- **多分支复盘**：在任意位置走出与主线不同的着法即生成支线；"新建分支"可先待命再落子，"删除分支"删除当前支线。棋谱面板主线按回合显示，支线按 `1.d4 Nf6`、`1.… c5 2.Nf3` 格式显示，并随当前着法自动横向滚动；当前支线与当前着法都有高亮。
- **终局结果**：主线最后一步下方显示 `1-0 · 白棋获胜`、`0-1 · 黑棋获胜` 或 `½-½ · 平局`。
- **棋谱面板**：显示双方得子，重叠紧凑排布不跑版；所有反馈都在面板内的一行小字上完成，没有浮动提示框。
- **摆棋**：自由摆放研究局面，支持选择移动、擦除、放置与拖拽；可设置先手方与双方易位权利，导出准确 FEN，或带着当前局面直接去复盘续走。
- **界面**：报纸风视觉，浅色棋盘以细线分格，暖灰纸色背景，单一低饱和深红强调色，按钮统一为细边框幽灵样式。
- **首页**：居中 logo、随机生成并缓慢旋转的棋子飘落背景；鼠标为黑王指针（带锁定标记），黑马保持固定间距在后方跟随，静止时在附近小范围蹦跳。
