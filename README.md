# JXchess

面向中文棋手的开源免费国际象棋工具。0.x 阶段做单机学棋工具，先从复盘与摆棋做起；引擎分析、揭棋与盲棋、账号在后续版本，联网功能安排在 1.x。

当前状态：v0.1.0 发布准备中。

> ⚠️ 网页版必须通过本地服务或部署后的网址访问，不能直接双击 HTML 文件打开。
> 本工程用 TypeScript 编写，棋盘等内容在浏览器中动态生成，直接打开文件只会看到空骨架。
> 想双击就用，请使用下方的桌面版安装包。

## 快速开始

```bash
cd v0.1
npm install        # 首次运行前执行，安装依赖
npm run dev        # 启动本地服务，然后访问 http://localhost:5173
```

- 首页 http://localhost:5173/index.html
- 复盘 http://localhost:5173/review.html
- 摆棋 http://localhost:5173/editor.html

其他命令：

```bash
npm run build      # 类型检查并构建，产物输出到 v0.1/dist
npm run preview    # 在本地预览构建产物
npm run app        # 以桌面窗口方式运行（Electron）
npm run package    # 打包 Windows 安装版与免安装版，产物在 v0.1/release
```

## 功能

- 复盘：PGN 导入导出、逐步回放与任意跳转、点击或拖拽走子、合法性校验与升变选择、被将军时的描边提醒、木质敲击音效、棋盘翻转。
- 多分支复盘：在任意位置走出不同着法即生成支线，可切换“新建分支”待命、删除当前支线；棋谱面板主线按回合显示，支线按 `1.d4 Nf6`、`1.… c5 2.Nf3` 形式显示并自动横向滚动跟随当前着法。
- 终局结果：主线最后一步下方显示 `1-0 · 白棋获胜`、`0-1 · 黑棋获胜` 或 `½-½ · 平局`。
- 摆棋：自由摆放研究局面，支持选择移动、擦除、放置与拖拽；可设置先手方与双方易位权利，导出准确 FEN 或带着局面直接去复盘。
- 界面：报纸风视觉（浅色棋盘配细线分格、暖灰纸色背景、单一低饱和深红强调色、细边框幽灵按钮）；复盘与摆棋页全程无浮动提示框，反馈显示在棋谱面板内的一行小字上。
- 首页：居中 logo、随机生成的棋子飘落背景，鼠标为黑王指针、黑马保持固定间距在后方跟随并游走。
